# Överfullt cykelrum

Det finns alldeles för många cyklar i vårt cykelrum, det gör att de medlemmar som cyklar dagligen har svårt att få ut sina cyklar.

Styrelsen har beslutat att uppmana alla medlemmar som inte använder sina cyklar dagligen att flytta dem till det större **cykelrummet på nr 43**, man kan komma dit via den vanliga ingången från gatan och inte via garaget.   
Detta gäller framförallt cyklar som står på marken, inte dem som hänger upp. Vi kommer inom någon vecka att be Stena att flytta alla cyklar som är kvar under dagen om ni inte gör det själv.
