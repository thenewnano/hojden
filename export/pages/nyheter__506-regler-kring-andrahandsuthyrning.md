# Regler kring andrahandsuthyrning

Styrelsen vill påminna medlemmar att det är **absolut inte tillåtet** att hyra sin lägenhet i andra hand utan att ansöka om styrelsens medgivande, föreningen behöver veta vilka som bor i fastigheten, i regel får man ansöka om det ett år om gången.

För att se vad som kan anses som godtagbara skäl och blanketter se länken nedan, olovlig uthyrning i andra hand kan leda att man förlorar rätten att bruka sin lägenhet, och tvingas sälja den.
